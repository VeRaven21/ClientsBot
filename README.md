# ClientsBot

Telegram-бот для управления записями клиентов на услуги с системой уведомлений и администрированием.

## Описание

ClientsBot - это полнофункциональный бот для автоматизации записи клиентов на услуги. Бот поддерживает три типа пользователей: клиенты, сотрудники (мастера) и администраторы. Каждая роль имеет свой набор функций и интерфейс.

## Возможности

### Для клиентов
- 📅 Запись на услуги с выбором даты, времени и мастера
- 👀 Просмотр активных заказов
- 🔔 Автоматические напоминания за 2 часа до записи
- 🗑️ Удаление аккаунта

### Для сотрудников (мастеров)
- 📋 Просмотр своих заказов по датам
- 🔔 Уведомления о новых записях
- 📅 Навигация по календарю заказов

### Для администраторов
- 👥 Управление пользователями (просмотр статистики)
- 💼 Управление услугами (добавление, редактирование, удаление)
- 👷 Управление сотрудниками (добавление, удаление, просмотр заказов)
- 📊 Просмотр статистики заказов

## Технологии

- **Python 3.14** - основной язык программирования
- **aiogram 3.x** - фреймворк для работы с Telegram Bot API
- **SQLAlchemy 2.x** - ORM для работы с базой данных
- **PostgreSQL** - база данных
- **Docker & Docker Compose** - контейнеризация
- **uv** - менеджер зависимостей Python

## Архитектура

Проект следует многослойной архитектуре:

```
Роутеры (routers/) → Сервисы (services/) → CRUD (crud/) → База данных
```

### Структура проекта

```
src/
├── routers/          # Обработчики команд и callback'ов
│   ├── admin/        # Панель администратора
│   ├── worker/       # Панель сотрудника
│   └── client/       # Панель клиента
├── services/         # Бизнес-логика
├── crud/             # Операции с базой данных
├── database/         # Модели базы данных
├── core/             # Конфигурация и настройки
└── models/           # Pydantic модели
```

## Установка и запуск

### Требования

- Docker
- Docker Compose

### Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/ClientsBot.git
cd ClientsBot
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Заполните переменные окружения в `.env`:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789,987654321

POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_password
POSTGRES_DB=clientsbot
DATABASE_URL=postgresql+asyncpg://postgres:your_password@db:5432/clientsbot
```

4. Запустите проект:
```bash
docker-compose up -d
```

5. Проверьте логи:
```bash
docker-compose logs -f bot
```

### Остановка

```bash
docker-compose down
```

### Пересборка после изменений

```bash
docker-compose build
docker-compose up -d
```

## Конфигурация

### Переменные окружения

| Переменная | Описание | Обязательная |
|------------|----------|--------------|
| `BOT_TOKEN` | Токен Telegram бота от @BotFather | Да |
| `ADMIN_IDS` | ID администраторов через запятую | Да |
| `POSTGRES_USER` | Имя пользователя PostgreSQL | Да |
| `POSTGRES_PASSWORD` | Пароль PostgreSQL | Да |
| `POSTGRES_DB` | Название базы данных | Да |
| `DATABASE_URL` | URL подключения к базе данных | Да |

### Рабочее время

По умолчанию бот работает с записями в диапазоне **9:00 - 18:00**.

Для изменения отредактируйте функцию `generate_time_slots()` в `src/services/client_service.py`:

```python
def generate_time_slots(date: datetime, step_minutes: int = 30) -> List[datetime]:
    start_hour = 9   # Начало рабочего дня
    end_hour = 18    # Конец рабочего дня
    # ...
```

### Интервал записи

По умолчанию шаг записи - **30 минут**.

Для изменения передайте параметр `step_minutes` в функцию `generate_time_slots()`.

## Использование

### Первый запуск

1. Отправьте боту команду `/start`
2. Первый пользователь с ID из `ADMIN_IDS` получит роль администратора
3. Остальные пользователи по умолчанию получают роль клиента

### Добавление услуг

1. Войдите как администратор
2. Выберите "Управление услугами"
3. Нажмите "Добавить услугу"
4. Введите название, цену и длительность

### Добавление сотрудников

1. Войдите как администратор
2. Выберите "Управление сотрудниками"
3. Нажмите "Добавить сотрудника"
4. Отправьте контакт или username пользователя

### Создание записи

1. Войдите как клиент
2. Выберите "Заказать услугу"
3. Выберите услугу из списка
4. Выберите дату (навигация стрелками)
5. Выберите время
6. Выберите свободного мастера
7. Подтвердите запись

## Система напоминаний

Бот автоматически отправляет напоминания клиентам за **2 часа** до записи.

Проверка выполняется каждые **10 минут** фоновой задачей.

Для изменения интервала отредактируйте `src/scheduler.py`:

```python
async def reminder_task(bot: Bot):
    while True:
        # ...
        await asyncio.sleep(600)  # 600 секунд = 10 минут
```
